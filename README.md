# iudog-randimg：极简随机图床系统
一个基于PHP开发的轻量级、**无需数据库**的随机图床系统。  
专为个人用户设计，追求代码极简与运行高效。  
*真的超级简洁，超级简单易用。*

## 📝 使用方式：
1. 上传压缩包并解压即成功部署
2. 访问域名，登录。  
&emsp;&emsp;默认账号:`admin`，密码:`123456`，请及时在配置文件`peizhi.php_date.php`中修改。
3. 在“文件夹管理”中创建分类，随后即可在首页上传图片。
4. 调用 `域名/suiji.php?id=链接标识符` 即可在外部网页引用随机图片。

## ✨ 系统特性：
- **无数据库**：完全基于文件存储（JSON编码），无需配置MySQL等数据库，上传即用，迁移极其简单。（~~没学过数据库，懒得学~~不想用
- **极简主义**：保持最纯净的逻辑，去除一切不必要的功能（~~其实是我水平不够~~
- **不挑环境**：虚拟主机都能部署，无需安装扩展，有php就能使。

## 🚀 核心功能：
- **图片管理**：支持按文件夹分类上传、预览和管理图片。
- **文件夹管理**：一键创建、修改、删除文件夹及其关联内容。
- **随机链接**：通过链接随机获取文件夹中的图片。
- **混合链接**：支持将多个文件夹组合，创建一个多目录图片混合的随机链接。
- **一键复制**：前端集成剪切板 API，方便快速获取图片链接或随机接口地址。

## 🛠️ 技术栈：
- **后端**：PHP(原生逻辑，无框架依赖)
- **前端**：原生JavaScript(无框架依赖) + CSS3动画
- **存储**：本地文件系统 + 加密PHP数据文件
